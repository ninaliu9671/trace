# Trace 履迹 · 项目目录结构

> 本文档说明哪些文件/文件夹需要你手动创建，哪些由 Claude Code 自动生成。
> 在启动 Claude Code 之前，先完成「你来创建」的部分。

---

## 一、你需要手动创建的内容

### 第一步：创建项目文件夹并初始化

在终端执行：

```bash
# 1. 创建 Next.js 项目（这一条命令会自动生成大部分基础文件）
npx create-next-app@latest trace --typescript --tailwind --app --no-src-dir --import-alias "@/*"

# 2. 进入项目文件夹
cd trace

# 3. 安装依赖
npm install openai @supabase/supabase-js @supabase/ssr

# 4. 启动开发服务器确认能跑起来
npm run dev
```

### 第二步：在根目录创建这些文件（你手动创建）

```
trace/
├── SPEC.md           ← 从 SPEC.md 文档复制内容粘贴进去
├── DESIGN.md         ← 从 DESIGN.md 文档复制内容粘贴进去
├── tasks/            ← 创建这个文件夹
│   └── 01_ProfilePage_框架.md   ← 从 task 文档复制内容粘贴进去
└── .env.local        ← 手动创建，填入你的 Key（见下方说明）
```

### 第三步：填写 .env.local

```bash
# .env.local 内容（替换成你自己的 Key）
DEEPSEEK_API_KEY=sk-你的DeepSeek密钥
NEXT_PUBLIC_SUPABASE_URL=https://你的项目.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ开头的anon密钥
SUPABASE_SERVICE_ROLE_KEY=eyJ开头的service_role密钥
```

**获取方式：**
- DeepSeek API Key：https://platform.deepseek.com → API Keys
- Supabase URL 和 Key：https://supabase.com → 你的项目 → Settings → API

### 第四步：在 Supabase 执行建表 SQL

打开 https://supabase.com → 你的项目 → SQL Editor
把开发文档第十章的 SQL 全部粘贴进去执行。

## 四、启动 Claude Code 的方式

文件夹和基础文件准备好后，在项目根目录启动：

```bash
# 在 trace/ 文件夹内执行
claude
```

然后用这句话开始第一个任务：

```
请先读取 SPEC.md、DESIGN.md、tasks/01_ProfilePage_框架.md 三个文件，
然后严格按照 task 文件的要求完成当前任务。
完成后告诉我做了什么，不要做 task 文件「不做什么」里列出的内容。
```

## 五、Git 和 Vercel 配置（一次性）

```bash
# 1. 初始化 Git
git init
git add .
git commit -m "init: project setup"

# 2. 推到 GitHub
# 先在 github.com 创建一个空仓库 trace
git remote add origin https://github.com/你的用户名/trace.git
git push -u origin main

# 3. 在 Vercel 导入
# 打开 vercel.com → Add New Project → 选择 trace 仓库
# 在 Environment Variables 里添加 .env.local 里的所有变量
# 点 Deploy
```

之后每次推代码，Vercel 自动部署：

```bash
git add .
git commit -m "feat: 完成 ProfilePage 框架"
git push
# → Vercel 自动开始部署，约 1 分钟后线上更新
```
